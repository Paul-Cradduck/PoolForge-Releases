# PoolForge Releases

Pre-built binaries and install scripts for [PoolForge](https://github.com/Paul-Cradduck/PoolForge) — open-source hybrid RAID storage manager for Ubuntu LTS.

## Install

```bash
curl -sSL https://raw.githubusercontent.com/Paul-Cradduck/PoolForge-Releases/main/install.sh | sudo bash
```

## Uninstall

```bash
curl -sSL https://raw.githubusercontent.com/Paul-Cradduck/PoolForge-Releases/main/uninstall.sh | sudo bash
```

## Updates

PoolForge checks this repository for new releases automatically. Updates can be triggered from the web dashboard or CLI.
